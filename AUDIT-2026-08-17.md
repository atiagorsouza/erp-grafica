## ⚠️ Erros Encontrados e Registrados

### 1️⃣ Vulnerabilidades npm (npm audit)

**Descrição**: 3+ vulnerabilidades high/moderate severity em dependências

```
3 high severity vulnerabilities
4 moderate vulnerabilities
```

**Linha**: Apareceu em todos os `npm install` durante instalação/updates  
**Severidade**: 🟡 MÉDIA (não bloqueia, requer revisão de dependências)  
**Recomendação**: Executar `npm audit fix --force` após validação com time

**Arquivos afetados**:
- `package.json` / `package-lock.json`

**Como Reproduzir**:
```bash
cd /www/wwwroot/erp-grafica
npm audit
```

---

### 2️⃣ pg_dump Falhou em Update

**Descrição**: Backup do PostgreSQL falhou com aviso mas não bloqueou update

```
pg_dump falhou — backup do banco ignorado
```

**Linha**: `scripts/update.sh` linha ~30  
**Severidade**: 🟠 ALTA (backup incompleto)  
**Causa Provável**: `pg_dump` pode não estar no PATH ou acesso negado  
**Recomendação**: Verificar se `pg_dump` está instalado e acessível

**Teste**:
```bash
which pg_dump
pg_dump --version
sudo -u postgres pg_dump app_db > test-backup.sql
```

---

### 3️⃣ Erro de Dependência no install.sh

**Descrição**: `drizzle-orm` não instalado como produção, causou erro em `npm run db:push`

```
Error please install required packages: 'drizzle-orm'
```

**Linha**: `scripts/install.sh` durante fase de schema  
**Severidade**: 🟡 MÉDIA (bloqueou mas foi contornado com `npm install`)  
**Causa**: `npm install --omit=dev` não instala `drizzle-orm` (está em dependencies mas pode ter sido omitido)  
**Recomendação**: Alterar estratégia de instalação em `scripts/install.sh`

**Arquivo afetado**:
- `scripts/install.sh` (linhas ~40-50)
- `package.json` verificar se `drizzle-orm` está em `dependencies`

**Como Reproduzir**:
```bash
npm install --omit=dev
npm run db:push  # Falha aqui
```

**Solução Aplicada**: Executar `npm install` sem flags após instalação inicial

## 🔧 Conflito de Infraestrutura Resolvido

**Problema**: 2 PostgreSQL rodando simultaneamente (aPanel + Debian)

**Resolução**:
- ✅ Parado PostgreSQL Debian (porta 5433)
- ✅ Mantido PostgreSQL aPanel (porta 5432)
- ✅ Criado database `app_db` no PostgreSQL aPanel correto
- ✅ Configurado `.env` para apontar para port 5432
