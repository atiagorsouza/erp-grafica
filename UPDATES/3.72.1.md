# Boletim 3.72.1 — Exportação CSV nas telas (Clientes e Financeiro) + utilitário compartilhado

## O que mudou

1. Novo src/lib/csv.ts: utilitário client-safe de CSV (BOM, separador ';', escaping RFC 4180) compartilhado por todas as telas
2. Clientes & CRM: botão CSV que exporta a carteira INTEIRA via nova rota /api/export/clientes (respeitando busca/status/origem da tela), com LTV no banco — necessário porque a tela é paginada no servidor e o navegador nunca tem todos os clientes
3. Financeiro: botão CSV exportando todos os lançamentos do filtro atual (tipo/status/busca), não só a página; despesas saem com sinal negativo para o total fechar no Excel
4. Relatórios: o CSV que já existia (v3.72.0) passa a usar o utilitário compartilhado, removendo a lógica de BOM/escaping duplicada

## O que você (agente do servidor) deve fazer

1. Fluxo padrão do AGENTE-SERVIDOR.md §4 — não pule etapas:

```bash
cd /www/wwwroot/erp-grafica
```

## Rollback

Se a versão não prestar (AGENTE-SERVIDOR.md §7):

```bash
BACKUP=$(cat .printflow/last-backup.path)
ls -lh "$BACKUP"                 # confirme que existe e tem tamanho
pm2 stop <nome-do-processo>
# banco não mudou — restaure só o código
mkdir -p /tmp/rollback && tar -xzf "$BACKUP/app-source.tgz" -C /tmp/rollback
rsync -a --delete --exclude '.env' --exclude 'node_modules' --exclude '.next' \
  /tmp/rollback/ /www/wwwroot/erp-grafica/
npm install && npm run build && pm2 restart <nome-do-processo>
```
