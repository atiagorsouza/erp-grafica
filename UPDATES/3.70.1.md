# Boletim 3.70.1 — Protocolo do agente do servidor

## O que mudou

1. **`AGENTE-SERVIDOR.md`** na raiz: manual de operação permanente para
   o agente que mantém a produção (fluxo de update, regras de ouro,
   rollback, política de branch, portal Hostinger).
2. **`scripts/agente-verificar.mjs`**: comando somente-leitura que
   compara versão do banco × repositório e lista os boletins
   `UPDATES/*.md` pendentes, na ordem, com os próximos passos.
3. **Pasta `UPDATES/`**: boletim por versão (este arquivo é o primeiro
   "oficial"; o da 3.70.0 foi criado junto).
4. **Portal Hostinger**: convenção criada — código do portal em
   `portal-hostinger/` (ainda vazio), empacotador
   `scripts/empacotar-portal.sh` gera `release/portal-v<versão>-<data>.zip`
   com LEIA-ME de implantação para subir na Hostinger.

## O que você (agente) deve fazer

1. Leia `AGENTE-SERVIDOR.md` na íntegra (uma vez só — ele é o manual).
2. Fluxo padrão do §4:

```bash
git pull origin main
bash scripts/update.sh
pm2 restart <nome>            # ou bash scripts/start.sh
set -a; source .env; set +a && npm run e2e:smoke
node scripts/check-version.mjs
node scripts/agente-verificar.mjs   # deve dizer "ATUALIZADO"
```

## Como validar

- `/api/version` → `"version":"3.70.1"` e `"upToDate":true`
- `node scripts/agente-verificar.mjs` → situação **ATUALIZADO**
- Nenhuma mudança funcional no ERP: é release de processo/documentação

## Rollback

Desnecessário (não altera banco nem comportamento). Se algo estranho
aparecer, trate como incidente normal (§7 do manual).
